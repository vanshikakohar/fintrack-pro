# 💰 FinTrack – Personal Finance Tracker

FinTrack is a **full-stack personal finance management web application** that helps users track income, expenses, and financial habits efficiently.

The app is built using the **MERN stack** with a clean UI and secure backend architecture, focusing on real-world use cases.

---

## 🚀 Features

- User authentication with JWT
- Add, edit, and delete transactions
- Income & expense categorization
- Real-time balance calculation
- Monthly and daily insights
- Secure REST APIs
- Responsive UI

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios
- Recharts / Chart.js

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
